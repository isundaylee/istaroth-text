# Talk Group: 热拉尔 (NpcGroup 7488)

## Talk 0

旅行者: 检查？
基拉: 按照新规定，我们有权力对任何具有潜在风险的人士进行抽检，包括但不限于行李检查与个人情况询问。
基拉: 如有任何问题，请向运输局反馈。

## Talk 1

热拉尔: 这种事怎么会发生在我身上！真是太不公平了——

## Talk 2

旅行者: 发生什么事了？
热拉尔: 说起来你可能都不会相信，朋友——我，一个从枫丹来的游客，竟然被拦下来抽检了，理由是「为了至冬的安全」！
热拉尔: 于是我问他们：「我看起来有什么地方可能威胁到至冬的安全吗？」
热拉尔: 工作人员回答我：「您背了一个包。我们需要确认您的包里是否藏有武器、晶矿、外来生物，或一切其他可疑物品。」
热拉尔: 于是我问她：「刚刚进去的那个至冬人，步履匆匆、神情警惕，最重要的是——背的包比我的大多了！你们为什么不抽检她？」
热拉尔: 工作人员回答我：「如果您对我们的判断标准有什么疑问，可以向运输局反馈。」

## Talk 3

旅行者: 再见。
热拉尔: 再见，朋友！唉，希望你不要像我一样倒霉。
