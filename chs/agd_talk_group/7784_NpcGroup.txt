# Talk Group: 伊格纳托夫 (NpcGroup 7784)

## Talk 0

伊格纳托夫: 「善于欺骗自己的人，生活得最快活…」

## Talk 1

旅行者: …什么？
伊格纳托夫: 啊…！对不起，打扰到您用餐了么？我不小心又把书上的句子念出来了…
伊格纳托夫: 您需要我帮什么忙？是点餐，还是清理桌子？

## Talk 2

旅行者: 再见。
伊格纳托夫: 啊…好、好的。再见…

## Talk 3

旅行者: 这倒是没有…你在看什么书？
伊格纳托夫: 是哲列兹诺夫先生给我的《惩罚》。唉，请您别告诉杜斯塔娅，否则她又要叹气了。
伊格纳托夫: 但请您也别误会，杜斯塔娅是我最好的朋友，多亏了她说服了我的父母，我才能在这里工作…
伊格纳托夫: 否则，以我父母的性格，是绝对不会容许我待在这里的…不、不过，我的父母也不是坏人，他们对我也很好…

## Talk 4

旅行者: 怎么感觉每个人都很好…
伊格纳托夫: …我父母不想我出来工作，是因为我身体太弱，不愿我生病。
伊格纳托夫: 杜斯塔娅想让我看点别的书，是因为她觉得…呵，这些书让我的心情越来越忧郁。
伊格纳托夫: 她们的确在关心着我，呵护着我，我非常感谢她们。但…抱歉，或许真的是因为我这个人性情古怪吧…
伊格纳托夫: 我总想着出去，想着跨出这一潭柔和的温泉，自己探入刺骨的冰窟里去。
伊格纳托夫: 哲列兹诺夫先生说，这是我自己正渴求着独属于自我的成长，并且又塞给了我一堆厚厚的书，说或许我能在这些书里找到答案…
伊格纳托夫: 然后…呵呵，他就被杜斯塔娅叉着腰请出去了。走的时候还又朝着我扮了个鬼脸。
伊格纳托夫: …啊！我、我不能再聊下去了，我得去工作了，抱歉，如果您需要帮忙的话，直接叫我就行。
