# Talk Group: NpcGroup - 9131

## Talk 0

尼可: 哦哦，这里不是那个谁的蜷缩维度象限变幻技术嘛。
尼可: 配合你的审美，呈现的效果相当不错嘛。

## Talk 1

旅行者: 在这里还习惯吗？
尼可: 像是回到了曾经老家的感觉。你知道吧，就是「天空岛」。想也知道，它的内外的大小肯定是有些文章的。
尼可: 等等，这个是可以说的嘛？
尼可: 嗯，应该没问题。毕竟不涉及我早就已经丢失的知识库权限，只是个体的记忆罢了。
旅行者: 知识库权限？
尼可: 哎呀，这个就不能细说了。你就当图书馆钥匙被没收了吧。
尼可: 不过姐妹们私藏书籍副本不交还的有不少。甚至私藏钥匙的也有一个…或者两个？
尼可: 优等生心眼都多，像我这样知足常乐比较好。
尼可: 虽然我也留下了一些知识啦，但那些都是图书馆最后闭馆那天默认我不用还的！
旅行者: 你可别在蒙德借书…
尼可: 为什么？哦，我知道了。艾莉丝说过，他们的图书管理员看起来懒洋洋的，其实对于追回图书很有手段。

## Talk 2

旅行者: 想一起聊聊天吗？
尼可: 好呀好呀。你知道的，我最喜欢聊天了。但可以畅所欲言聊天的朋友并不多，毕竟在全世界面前都要伪装神秘端庄嘛。
尼可: 想要聊些什么？
尼可: 天文地理、艾莉丝的坏话，我全都没问题。
    Option 1:
        旅行者: 艾莉丝的坏话。
        尼可: 哎呀，我也就说说。怎么能真的在别人背后说她坏话呢。
        尼可: 这是安雅教我的为人处世准则。八面玲珑、左右逢源也是有底线的。
        尼可: 永远不要出卖亲朋好友——哪怕是背后说坏话这种事。
        尼可: 好吧好吧。别这样看我，我才不是怕了她呢。说一个她不会在意的，我想想。
        尼可: 艾莉丝给莱茵多特设计的出场介绍魔法，用了好多套模版。看着一点审美都没有。
    Option 2:
        旅行者: 说说洞天内才能说的…
        尼可: 嗯，没错。洞天之内或许隔绝了外界天地，探查或许没那么容易。
        尼可: 但是强大的回溯还是可以起作用的。比如，你在这里提到被修订的历史，出去之后也会什么都不记得。不会给人空子钻的。
        尼可: 很虚无，但这也是为了规划的严谨性。
        尼可: 我还是觉得别说这些东西比较好。不过…如果是你的话，或许没问题。

## Talk 3

旅行者: 有什么想做的吗？
尼可: 我现在就想用最大声音呼喊。反正你这里周围生灵稀少。上次艾莉丝测过呢，我最大音量可以传播一百米内所有生命的心灵。
    Option 1:
        旅行者: …别，壶里有别的朋友。
        尼可: 对哦。还有其他被你邀请来的朋友。
    Option 2:
        旅行者: …阿圆钻进壶里也防不住。
        尼可: 噢，也是。那只壶灵怪可爱的，波及到她不太好。
尼可: 那还是算了吧。我想想哦，难得来洞天，要做些什么有意思的事情呢？
旅行者: 把这里当成普通的庭院就好。
尼可: 确实。是我执着于本质，忽略表象了。这里虽然也是一种洞天，但是它更是你的小家。
尼可: 不一定要把这里当试验场。当成串门就好了。
尼可: 那，我想在你这里埋宝箱，设计谜题。
    Option 1:
        旅行者: 你去参加O的计划不是更有效率。
        尼可: 哦，也对呢！不过这也不影响嘛。
    Option 2:
        旅行者: 要怎么开始呢？
尼可: 我们来研究用墙做一个有趣的迷宫吧。
旅行者: 宝箱你能提供吗？
尼可: 交给我吧！对我们天使来说，箱子比内容重要。我一定会弄一个很厉害的箱子的。
尼可: 至于内容。就随便丢些摩拉和卷心菜进去好了。
