# Talk Group: 卢普欣 (NpcGroup 7531)

## Talk 0

旅行者: 出什么事了吗？
奥维先尼科夫: 您瞧瞧，现在至冬堡的酒馆，都开始拿火水兑果汁喝了！
奥维先尼科夫: 这叫个什么事？早年间喝火水都是有规矩的，就得一口直接灌下去，再配上点酸黄瓜和黑麦面包，那味道才正宗。
奥维先尼科夫: 以前我家里长辈跟着老沙皇南征北战的时候，都是这么吃的！
奥维先尼科夫: 再瞧瞧现在，这算怎么回事？一个个搞得花里胡哨的，都没有当年的味道了。

## Talk 1

卢普欣: 多么美妙，这才称得上真正的艺术！

## Talk 2

旅行者: 你说的艺术是指？
卢普欣: 你感受不到这里的空气里都充满了艺术的气息吗？
卢普欣: 没有兜售庸俗工艺品的叫卖声，也没有人会谈论《先驱报》上的二流文章…总的来说，就是一点人味都没有，真是太棒了。
卢普欣: 这就是上流社会啊！妖精贵族们几千年历史的底蕴，果然不是那些暴发户人类能比得了的。

## Talk 3

旅行者: 不打扰了。
卢普欣: 庸俗，太庸俗了！

## Talk 4

旅行者: 你不也是人类吗？
卢普欣: 话是这么说，但我的品味早就超越了人类！在精神上，我已经和妖精贵族们站在了同样的高度。
卢普欣: 哎，多么可怜！我那被禁锢在凡俗肉体里的不羁灵魂。

## Talk 5

旅行者: 妖精也不一定就懂艺术吧…
卢普欣: 那不重要，重要的是熔炼在他们血脉里的高贵气息，是那份恰到好处的沉静与疯狂！
卢普欣: 要是你也能拥有像我一样高雅的品味，自然就能明白了。
