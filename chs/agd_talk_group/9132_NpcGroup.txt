# Talk Group: NpcGroup - 9132

## Talk 0

布伦妮: 这就是传说中的尘歌壶？没想到里面是这样的构造…
布伦妮: 不止尘歌壶，我还听说过很多其他奇妙的法宝和机关，哼哼。

## Talk 1

旅行者: 在这里还习惯吗？
布伦妮: 不用担心，我又不是小孩子了，不会因为认床睡不着的。
布伦妮: 即便是跟着商队在路上居无定所的日子里，我也没有过水土不服的状况哦。
旅行者: 话说，布伦妮住在蒙德哪里？
布伦妮: 我住在蒙德的远房亲戚家里，虽说是亲戚，其实是爷爷的表妹的儿子的…
布伦妮: 算了，关系太复杂了。总之就是那种「年纪比我大但按辈分应该叫我一声小姑」的关系。
布伦妮: 就因为爸妈在信里专门委托了她要「看紧点」，每天还有门禁时间…这对吗？哪有给小姑设置门禁的道理。
旅行者: 那在我这里玩没关系吗？
布伦妮: 哦，完全没问题，我报备过了。
布伦妮: 顺便一问，在这里有什么规矩吗？门禁啊，不能去的区域啊，不能动的家具啊…
旅行者: 没有，那是大人才喜欢定的东西。
布伦妮: 这么好？！
布伦妮: 我是说，这么好的度假胜地，大家对你家的评价一定很高。
布伦妮: 我也一样！

## Talk 2

旅行者: 想一起聊聊天吗？
布伦妮: 既然你提到了，我们就来聊聊那个「终极反派」——艾莉丝吧。
旅行者: 你们俩都是我的朋友…
布伦妮: 别误会，不是要你现在就站队。魔女蛊惑人心的花样非常多，就算暂时被蒙蔽了也是可以被理解的。
布伦妮: 我相信你的眼睛是雪亮的，谁对谁错你迟早会明辨！
布伦妮: 只是我最近在反思，为什么每一次明面上是我「战胜」了她，结果却总是变成「按照她的剧本演完了下一幕」？
布伦妮: 好不甘心！我需要一个熟悉魔女的人帮我复盘！
布伦妮: 你说艾莉丝的「算盘」里到底有什么逻辑？
布伦妮: 你这么聪明，能帮我想想怎么才能扳回一城吗？让她也尝尝「失算」的滋味！
旅行者: 有没有可能，她根本不讲逻辑…
布伦妮: ……！
布伦妮: 你说得对。那个邪恶巫婆，做事总是随心所欲，借着什么「有趣」的名义肆意妄为…
布伦妮: 那我该怎么对付她？
    Option 1:
        旅行者: 那就当个撒泼打滚的小孩…
    Option 2:
        旅行者: 用「魔法」打败「魔法」！
布伦妮: 谁会故意干那种又吵又闹，还会被人讨厌的事情啊！
布伦妮: 等等…你不对劲。我有理由怀疑你是魔女假扮的。
布伦妮: 难道你是…让我看看你的真面目——
    Option 1:
        旅行者: 其实是想让你不要想太多…
    Option 2:
        旅行者: 你也可以像孩子般随心所欲。
布伦妮: 唔…突然这么说，也不可能马上就做得到吧…
布伦妮: 至少得从可莉她们身上稍微学一学…

## Talk 3

旅行者: 有什么想做的吗？
布伦妮: 问得好，我决定采取你的建议，做一个实验。
布伦妮: 只是实验哦！试、试着当一天无忧无虑的普通的小孩…
布伦妮: 就一天！
旅行者: 一天也可以哦。
布伦妮: 所以我昨晚提前做了「热身」。
布伦妮: 把书合上，把文具收起来，还不断提醒自己——今天不需要得出任何结论。
旅行者: 然后呢？
布伦妮: 从睡觉前我就开始想：普通小孩现在应该在做什么？听故事？画画？喝睡前牛奶？该不会已经睡着了吧！
布伦妮: 想了很久，我都忘了怎么睡着的了，还差点错过自然醒的最佳时间。
旅行者: 你还是有点想太多了！
布伦妮: 唔…我也察觉到了。所以今天我决定执行「小孩要做的事情清单」。
旅行者: 这又是什么东西？
布伦妮: 第一项，睡醒先在床上打滚和翻身。然后被催起床，由于没有人催我，所以我装模作样地对着空气说了几句话。
布伦妮: 勉勉强强，算完成吧。
布伦妮: 第二项，挑食。我认真考虑过，但还是全吃了。
布伦妮: 所以在备注里写了失败。
布伦妮: 第三项是毫无节制地吃零食，这个最简单，我最喜欢这个任务。
布伦妮: …吃到一半我突然意识到，这项任务根本不合理！
布伦妮: 除了做梦，小孩子哪会有机会无节制吃零食啊？肯定会被大人阻止吧。
布伦妮: 第四项就更难了，玩没有实际意义的游戏。
布伦妮: 结果我的注意力，全跑去找游戏规则的漏洞了…
旅行者: 听上去很不顺利…
布伦妮: 对。所以现在我要开始闹情绪了！
布伦妮: 我要把清单收起来，然后宣布实验大失败！虽然失败了，但是我一点都不想管！
布伦妮: 不想找原因，不想听道理，就这样！
旅行者: 「闹情绪」也是清单里的一项吧？
布伦妮: 欸…你怎么知道的？！
    Option 1:
        旅行者: 因为不讲道理就是小孩子的特权。
    Option 2:
        旅行者: 你已经抓到精髓喽。
布伦妮: 哼。
