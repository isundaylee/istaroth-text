# Talk Group: 弗约尔斯卡娅 (NpcGroup 7888)

## Talk 0

弗约尔斯卡娅: 要是没人来车站，就是小镇好时节。

## Talk 1

旅行者: 好时节？
弗约尔斯卡娅: 是啊，好时节。没人来车站，就没有无穷无尽的工作。
弗约尔斯卡娅: 每天拿一样的工钱，未来的道路一眼就能望到头。而工作嘛，做得多了，没人欣赏；做得少了，没人在乎。
弗约尔斯卡娅: 既然如此，人少当然比人多好了——来到车站的旅客越少，活计就越少；活越少，我的责任就越小。您说对吧？

## Talk 2

旅行者: 再见。
弗约尔斯卡娅: 再见！

## Talk 3

旅行者: 这不对吧…
弗约尔斯卡娅: 再年轻个十岁，像莎戈娃那么大的时候，我也觉得这不对。
弗约尔斯卡娅: 莎戈娃…那个年轻的傻姑娘，还以为只要努力，就能出人头地。
弗约尔斯卡娅: 想当初，我年年都是凝露镇优秀列车员。人人都说，年轻的弗约尔斯卡娅是最有希望调任到至冬堡去的。
弗约尔斯卡娅: 可结果呢？年年我都在这车站，眼睁睁看着那些镇长亲戚家出来的、要么就是认识站长的列车员…看着他们一一升迁。
弗约尔斯卡娅: 从那以后，我就知道了。与其相信那些不着调的好话，不如舒舒服服过好自己的每一天。

## Talk 4

旅行者: 对！
弗约尔斯卡娅: 英雄所见略同，看来您也深谙工作之道。
弗约尔斯卡娅: 那个傻姑娘…您见着了吗？那边有个叫莎戈娃的列车员。她还想着，只要做得够多，就一定能被看见、被赏识，然后被提拔。
弗约尔斯卡娅: 提拔？哈…她不知道。在这个地方，做得越多，就只会得到更多的工作。
