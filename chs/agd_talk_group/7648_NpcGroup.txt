# Talk Group: NpcGroup - 7648

## Talk 0

尼基塔: 身为执灯士，必须时刻留意周围的异动。

## Talk 1

旅行者: 关于执灯人…

尼基塔: 执灯人是为了守护挪德卡莱的自由与和平而建立的组织。从铸灯者召集起第一批执灯士算起，已有五百年历史了。

尼基塔: 虽然是这么说，不过中间其实遭遇过不少几乎要使我们的传承断绝的危机，执灯人的军团也重建过多次。

尼基塔: 但无论如何，只要灯火象征的意志没有消灭，我们就会一次次浴火重生。

## Talk 2

旅行者: 关于皮拉米达城…

尼基塔: 皮拉米达城是我们执灯人的总部，传说是初代执灯长，铸灯者索洛维建造的。

尼基塔: 而在那之前，这里似乎曾是统治挪德卡莱的妖精总督的宫殿，你在地基的石垣上还能找到那时的徽章。

尼基塔: 要是这个说法没错的话，说不定在这里的地下，还埋藏着妖精总督的宝藏呢。

## Talk 3

旅行者: 真没想到你就是执灯长…

尼基塔: 怎么，你想象中的执灯长该是个身手矫健、一往无前的勇士，而不是像我这样的老头子？

尼基塔: 在我之前的上一任执灯长，的确是你想象中的样子，我也曾与他并肩作战…

尼基塔: 但我并没有像他那样的力量，如今的执灯人也不复当年，所以才必须处处小心谨慎。
