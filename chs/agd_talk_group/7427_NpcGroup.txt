# Talk Group: 希菲尔德 (NpcGroup 7427)

## Talk 0

希菲尔德: 呃…头好晕，怎么回事…这火水…

## Talk 1

旅行者: 你这是怎么了？
希菲尔德: 我…我喝了太多的火水…呃，我本来以为，可以喝点酒，说不定能够写出了不起的诗…
希菲尔德: 吟游诗人不就是这样吗，越喝越兴奋，在恍惚中得到佳句…
希菲尔德: 但是…呃…可是相较于啤酒，火水是不是太过了…现在只觉得头有点痛…呼…

## Talk 2

旅行者: 需要帮助吗？
希菲尔德: 没事，我只是…我只是火水喝得太猛了…
希菲尔德: 相信我，我可是蒙德人，我得信任我的蒙德人血统…想必再过一会儿就能适应火水了…

## Talk 3

旅行者: 看来您得少喝点。
希菲尔德: 也许吧…唉，可是都到了至冬，谁能忍住不尝尝当地的火水呢。
