# Talk Group: 纳费多夫 (NpcGroup 7420)

## Talk 0

纳费多夫: 这个单子好了，好，还有这道菜，上菜了，一号桌！嗯？…怎么了？客人。

## Talk 1

旅行者: 你是这家店的老板？
纳费多夫: 是的，这家由兽怪搭建，兽怪经营，为整个至冬所有食客服务的餐厅…的老板，就是我。
纳费多夫: 好了，您要来这儿只为了问这个，那恕我不能奉陪了，还有好多事要做呢。

## Talk 2

旅行者: 毛会不会掉进菜里…
纳费多夫: 当然不会，我们的厨师会清理完浮毛再上厨，也尽可能保证料理烹饪期间不会抖落不该进去的东西…
纳费多夫: 如果您…真的遇到了类似的情况，可以让侍者把菜撤走，我们重新为您做一份。

## Talk 3

旅行者: 没什么事。
纳费多夫: 那祝您用餐愉快，客人。
