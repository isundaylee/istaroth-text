# Talk Dialog

巴哈尔: 每个人都拿走假条了吗？
    Option 1:
        旅行者: 有人选择了其他奖励。
    Option 2:
        旅行者: 有人后来被取消了领取假条的资格。
    Option 3:
        旅行者: 每个人都拿走了假条。
巴哈尔: 为什么盒子里剩下一张假条？
    Option 1:
        旅行者: 得到这张假条的人连同盒子一起取走了。
    Option 2:
        旅行者: 是属于其他工作人员的假条。
    Option 3:
        旅行者: 这张假条废弃了。
巴哈尔: 假条现在的情况是…
    Option 1:
        旅行者: 所有假条都在应得假条者的手上。
    Option 2:
        旅行者: 有些假条被毁坏了。
    Option 3:
        旅行者: 有些假条没有被取走。
