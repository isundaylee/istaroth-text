# Talk Group: 波波豪 (NpcGroup 6530)

## Talk 0

波波豪: 悠悠纳塔，悠悠夏天！这位客人，欢迎来到特诺奇兹托克，欢迎来到悠悠度假村！登记入住请沿着沙滩往里走。

## Talk 1

旅行者: 特诺奇兹托克…？
波波豪: 特诺奇兹托克就是这片岛屿的名字，也就是我们现在站的地方。
波波豪: 在本地语言里，这个名字的意思是「岩石与刺梨的洞穴」。
波波豪: 可惜刺梨现在已经不再生长了，不管是诺奇特梨还是娜娜丝梨，大概是土地的营养发生了变化吧。

## Talk 2

旅行者: 悠悠度假村…？
波波豪: 欸？您难道不是收到了度假村的邀请函才过来的吗？那就让我为您再解答一下。
波波豪: 悠悠度假村是话事处兴建的一座大型夏日滨海度假区，内部还有分为多个不同的附属区域。它的选址就在纳塔最西边的特诺奇兹托克。
波波豪: 现在您只要顺着沙滩往里走可以办理入住，领取度假村纪念手册，然后开始您的夏日休闲之旅啦。

## Talk 3
