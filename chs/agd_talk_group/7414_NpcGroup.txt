# Talk Group: 格里戈里 (NpcGroup 7414)

## Talk 0

格里戈里: 来看看新进的商品吧！不过注意了，离开柜台钱货两讫，然后…原则上不接受赊账！

## Talk 1

旅行者: 让我看看有什么…
格里戈里: 看看吧，都是些刚进的好东西！

## Talk 2

旅行者: 我要赊账！
格里戈里: 哈哈，客人你看上去也不是什么穷酸人，还是算了吧，小店本就是成本经营…
格里戈里: 说正经的，名为赊账，其实大多也就是帮帮实在过不去的乡里乡亲，像您这样的，就不是「赊账」服务提供的对象啦。

## Talk 3

旅行者: 有很多人赊账吗？
格里戈里: …以前偶尔有，只不过最近数量多了起来。
格里戈里: 家家都有本难念的经，来我们「布莱茨卡」这儿买东西的也大多是居住在附近的居民，总有生活突遭变故，难以为继的时候…
格里戈里: 说是赊账，其实大部分赊的账呢，钱款也讨不回来，权当帮衬了。

## Talk 4

旅行者: 没什么想看的…
格里戈里: 是嘛，那等到了新货，你再看看，说不定有你想要的呢！

## Talk 5

阿罗夏: …这些就够了，谢谢你，格里戈里。
格里戈里: 行了，咱们哥俩还这么客气，我出去送货的时候，有时候还指望你帮忙呢。
阿罗夏: 那只是我应该做的。
格里戈里: 你又来了，得了，把这些肉干和饼子装好了，要不要再来点水果？看你又要出远门。
阿罗夏: 差不多吧。这次的捕猎，可能要花很长的时间。
格里戈里: 很危险？
阿罗夏: 每次狩猎都并不是那么安全，格里戈里。
格里戈里: 好吧…我是不懂狩猎，但要是情况不对，你可记得要掉头就跑啊。
阿罗夏: 当然，图加林总是能帮我找到捷径。
