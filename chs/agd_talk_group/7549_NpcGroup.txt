# Talk Group: 罗迪翁 (NpcGroup 7549)

## Talk 0

罗迪翁: 只要仔细、专注、用心去感应，你就能知道它的存在——雪堆里可是深埋着女巫的「大奖」呐！

## Talk 1

旅行者: 我也能拿到大奖吗？
罗迪翁: 当然，作为「女巫」的代理人，我会为你提供指引。不过，注意——你只有*五次机会*来获得大奖…

## Talk 2

旅行者: 哇，好多霜精围着你。
罗迪翁: 这些小家伙啊…以前我在大街上扫雪的时候，总是能遇到意外被困住的霜精。我帮了它们，所以那时候它们就总跟着我了。
罗迪翁: 现在我退休啦，不在大街上晃来晃去了，这些小家伙们也就来陪着我，围着我的摊子转。

## Talk 3

旅行者: 现在暂时没空…
罗迪翁: 不急，先去忙你自己的事情吧。

## Talk 4

旅行者: 它们不会捣乱吗？
罗迪翁: 哈哈，当然不会，从某种程度来说，它们也是「女巫」——
罗迪翁: 它们把雪堆堆成一样的大小，再把自己藏在其中一个雪堆中，每一轮寻宝结束之后，它们还要将被扫开的雪堆复原。
罗迪翁: 这些可爱的小家伙，真是省了我不少功夫呢…
