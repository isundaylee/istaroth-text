# Talk Group: 阿琳娜 (NpcGroup 7489)

## Talk 0

旅行者: 发生什么事了？
热拉尔: 说起来你可能都不会相信，朋友——我，一个从枫丹来的游客，竟然被拦下来抽检了，理由是「为了至冬的安全」！
热拉尔: 于是我问他们：「我看起来有什么地方可能威胁到至冬的安全吗？」
热拉尔: 工作人员回答我：「您背了一个包。我们需要确认您的包里是否藏有武器、晶矿、外来生物，或一切其他可疑物品。」
热拉尔: 于是我问她：「刚刚进去的那个至冬人，步履匆匆、神情警惕，最重要的是——背的包比我的大多了！你们为什么不抽检她？」
热拉尔: 工作人员回答我：「如果您对我们的判断标准有什么疑问，可以向运输局反馈。」

## Talk 1

阿琳娜: 有什么可以帮到你，亲爱的？是要询问列车班次、进行失物招领，还是想发布寻人启事？请别急，有事慢慢说。

## Talk 2

旅行者: 关于列车班次…
阿琳娜: 我非常明白你的心情，亲爱的。每一位旅客都关心自己要搭乘的列车，就如他们关心至冬的天气一样。
阿琳娜: 让我瞧瞧…哦！为什么不去售票窗口问问沃克列先斯基呢？他一定能解决所有关于列车班次的疑问。

## Talk 3

旅行者: 失物招领…
阿琳娜: 哦…真糟糕，亲爱的，你丢了什么吗？你一定很着急吧，我完全、完全理解你的心情。
阿琳娜: 不过别急，让我想想…唔，亲爱的，你确定是在车站里把东西弄丢了吗？
阿琳娜: 亲爱的，你再自己仔细找找吧？实在不行，去站台上问问恰金娜，她一定愿意帮你一起把东西找回来。

## Talk 4

旅行者: 发布寻人启事…
阿琳娜: 天呀，亲爱的，你和你的同伴走散了吗？多么令人焦急呀…
阿琳娜: 我来帮你想想…唔，与其发布寻人启事，然后坐在车站里等候，不如动身去找人，把主动权掌握在自己手中，是不是？
阿琳娜: 所以呀，亲爱的，你听我说，站台上的列车员一定愿意帮你一起找人——今天值班的是伊莉雅娜，还是索契科夫来着…
阿琳娜: 是谁都行，反正列车员都穿着一样的制服。你去站台上看看吧，亲爱的，保准一眼就能把他们认出来。

## Talk 5

旅行者: 没事。
阿琳娜: 那真是再好不过了，亲爱的。祝你旅途顺利！
