# Talk Group: 马蒙托夫 (NpcGroup 7481)

## Talk 0

马蒙托夫: 还没到我吗？还要等多久…不会误点吧…

## Talk 1

旅行者: 你是？
马蒙托夫: 欸？你认出我了？是我的读者吗？原来我已经这么出名了…

## Talk 2

旅行者: 看样子还要等很久吧。
马蒙托夫: 是啊。刚才有对年轻夫妇在这儿大吵了一架，列车员也不管管…可能管也管不动吧。
马蒙托夫: 我看他们吵完就各奔东西了，留在这儿的好像是他们的孩子，家庭不幸啊，怪可怜的。
马蒙托夫: 不过售票员要是再不快点解决他的问题，可怜的就是我了。排了这么久的队还误了列车的点，上哪儿说理去。

## Talk 3

旅行者: 不打扰了。
马蒙托夫: 你等的车已经到了吗？祝你一路顺风。

## Talk 4

旅行者: 什么读者？
马蒙托夫: 当然是《先驱报》的读者…等等，说起来报上没有刊过我本人的画片…抱歉，看来是我弄错了。
马蒙托夫: 实不相瞒，我在给《先驱报》的一个小板块供稿，编辑说近来这个板块很受读者欢迎，我还以为自己这就出名了呢。
马蒙托夫: 仔细研究查证写出来的列车研究屡遭拒稿，随手写的半真半假的列车故事却反响热烈，真是世事难料啊。
