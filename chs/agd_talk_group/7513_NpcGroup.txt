# Talk Group: 谢尔巴托夫 (NpcGroup 7513)

## Talk 0

谢尔巴托夫: 哎哎哎，这位朋友！对，说你呢！你想不想发财？

## Talk 1

旅行者: 你是？
谢尔巴托夫: 我是谁根本不重要，重要的是，我是那个马上要往你口袋里塞摩拉的人！
谢尔巴托夫: 我这么说吧，年轻人。这年头发大财，无非就靠三样：门路、手段，外加一点点破釜沉舟的决心。
谢尔巴托夫: 现在，门路和手段我都替你铺好了，就看你有没有这个决心，抓住这辈子可能只有一次的历史机遇了！

## Talk 2

旅行者: 不感兴趣，再见。
谢尔巴托夫: 唉？发财都不想吗？现在的年轻人真是…

## Talk 3

旅行者: 什么门路和手段？
谢尔巴托夫: 问得好！我就喜欢跟你这种聪明又谨慎的人说话，一点就透！
谢尔巴托夫: 先说门路。不瞒你说，我亲侄子佐托夫，就在皇都评议会高就！有这层关系罩着，咱们这买卖，稳赚不赔！
谢尔巴托夫: 至于手段嘛…风靡枫丹的「枫达」你总听说过吧？我这里，有它的至冬独家升级版——「冰达」的绝密配方！
谢尔巴托夫: 相比「枫达」那种软绵绵的冒泡小甜水，「冰达」最大的优势就在于够劲！只需一口，就能让你的喉咙体验到冰封般的快感！
谢尔巴托夫: 现在连设备带配方我都准备好了。我算过了，你只要随便投个一千万摩拉，一个月内包你回本！剩下的全是纯利润！
谢尔巴托夫: 不过事先声明啊，我可只会选择一位合作商。有位名叫尤洛娃女士已经在考虑了，你要是感兴趣，下手可得抓紧哦！

## Talk 4

旅行者: 听着就感觉不靠谱，再见…
谢尔巴托夫: 我跟你说，过了这个村可就没这个店了啊！
