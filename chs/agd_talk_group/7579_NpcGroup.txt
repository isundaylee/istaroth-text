# Talk Group: 柳芭娃 (NpcGroup 7579)

## Talk 0

柳芭娃: 呵，都这么大人了还这样，真是个笨蛋…

## Talk 1

旅行者: 说谁是笨蛋呢？
柳芭娃: 还能有谁，我家伊格纳沙那个木头！一天到晚脑子里只有赚钱，连句好听的话都不会说。你说，哪有这样的丈夫？
柳芭娃: 我都跟他说过多少次了，别去上那个夜班，他非不听，非说夜班工钱高！高能高出多少啊？都不够看病钱的。
柳芭娃: 哼，等他哪天真病倒了，我绝对天天坐在床头嘲笑他，还要喂他吃他最讨厌的红菜汤，看他以后还敢不敢不听我的！

## Talk 2

旅行者: 打扰了。
柳芭娃: 嗯，好的，再见。

## Talk 3

旅行者: 如果他是为了你攒钱呢？
柳芭娃: 那我也不同意！就他攒的那点钱，哪够在至冬堡买房子啊？买房都不知道算装修和家具的钱，真是笨死了！
柳芭娃: 不过嘛…偷偷告诉你哦，其实我自己也偷偷存了一笔钱。等他买房发现钱不够以后，我非得先晾他几天，急死他！
柳芭娃: 等他急得快哭了，我再把钱拍在他面前！给他好好长长记性，让他知道这个家到底谁说了算！
