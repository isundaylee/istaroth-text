# Talk Group: 别尔斯基 (NpcGroup 7585)

## Talk 0

别尔斯基: 要让雪橇追上火车，最少需要几条猎犬呢？

## Talk 1

旅行者: 你想玩雪橇吗？
别尔斯基: 当然了！不过，最好不要告诉我爸，他总说这东西非常非常危险。

## Talk 2

旅行者: 你家长呢？
别尔斯基: 就在那边咯，他平时会帮阿罗夏哥哥维护工作台。
别尔斯基: 话说回来，我之前就想用阿罗夏哥哥的工作台制作一把猎枪，但老爸他立刻拒绝了，明明阿罗夏哥哥已经答应了…
别尔斯基: 有机会的话，还是借阿罗夏哥哥的猎枪玩吧…

## Talk 3

旅行者: 雪橇也没那么危险吧？
别尔斯基: 对啊，我一直想做一件事，就是改造出一架能追上火车的雪橇！
别尔斯基: 但老爸听说之后就再也不让我碰雪橇了，然后一直跟我说这东西非常非常危险…
